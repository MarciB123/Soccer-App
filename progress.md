Last updated: March 9, 2026

## PROJECT CONTEXT

### What It Is
An AI-powered soccer training app for iOS and Android. Users go through an onboarding questionnaire, get a personalized training plan generated by Claude AI, and can chat with an AI coach named Coach Alex. Monthly subscription at $12.99/month with a 7-day free trial.

### Who It's For
- Primary: Youth players aged 13–17 in the USA
- Secondary: Young adults 17–25
- COPPA flow handles under-13 users (parental consent required)

### Solo Founder
One developer building and launching this alone.

### Monetization
- $12.99/month or $99.99/year (RevenueCat handles billing)
- 7-day free trial
- Target: 200+ paying subscribers before adding major new features

### Tech Stack
| Layer | Tool |
|---|---|
| Mobile | React Native + Expo SDK |
| Language | TypeScript |
| Navigation | Expo Router (file-based) |
| Styling | NativeWind v4 (Tailwind for RN) |
| State | Zustand (auth store + onboarding store) |
| Data Fetching | TanStack Query (React Query) |
| Backend/DB | Supabase (PostgreSQL + Auth + Storage + Edge Functions) |
| AI/LLM | Claude Sonnet 4.6 (Anthropic) via Supabase Edge Functions |
| Subscriptions | RevenueCat |
| Push Notifications | Expo Push |
| Icons | Ionicons (@expo/vector-icons) — NO emoji, all replaced |
